# 📦 SwiftEx Logistics Engine

A console-based courier sorting, tracking, and logistics simulation engine built in **C++17**. The project demonstrates custom data structures, graph algorithms, multithreading, file-based inter-process communication, and logistics simulation.

## 🚀 Features

* **Custom Data Structures**

  * Min Heap
  * Graph using adjacency lists
  * Hash Table for parcel tracking
  * Linked Lists
  * Custom implementations instead of STL containers such as `vector` and `map`

* **Intelligent Routing**

  * Uses **Dijkstra's Algorithm** for shortest-path calculation
  * Models a network of 8 cities
  * Supports dynamic road blockages

* **Smart Dispatch**

  * Uses a space-filling approach to optimize vehicle loading
  * Supports different vehicle types such as buses and trucks
  * Considers parcel priority during dispatch

* **Multithreaded Simulation**

  * Separates simulation processing from the user interface
  * Uses C++ threads and mutexes for synchronization

* **Parcel Tracking**

  * Hash-table based tracking system
  * Allows parcels to be located using their tracking information

* **Admin Panel**

  * Separate administrative interface
  * Displays system information, traffic conditions, lost parcels, and logs

## ▶️ How to Run

### Requirements

* Windows
* GCC / MinGW-w64
* C++17 compatible compiler

### 1. Compile the main engine

Open a terminal in the project directory and run:

```bash
g++ -std=c++17 source.cpp -o source.exe
```

### 2. Run the main engine

```powershell
.\source.exe
```

The main engine should be started **before** the admin panel because it creates and updates the files used by the administrative interface.

### 3. Compile the admin panel

Open another terminal in the same project directory and run:

```bash
g++ -std=c++17 admin.cpp -o admin.exe
```

### 4. Run the admin panel

```powershell
.\admin.exe
```

The admin panel reads the system information generated by the main simulation engine.

## 🧠 Data Structures & Algorithms

The project focuses on implementing core data structures and algorithms without relying heavily on STL containers.

### Linked List

Used for maintaining dynamically changing collections of objects.

### Min Heap

Used for priority-based processing and dispatch operations.

### Hash Table

Used to provide efficient parcel tracking and lookup.

### Graph

The logistics network is represented as a graph using adjacency lists.

### Dijkstra's Algorithm

Used to calculate shortest paths between cities in the logistics network.
